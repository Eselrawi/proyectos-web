# Proyectos web

Soy Raúl Gómez, desarrollador web junior. Aquí tienes los proyectos web que tengo publicados. Puedes entrar y probarlos desde el enlace de cada uno.

## Lumbre Errante

**[Probar la demo](https://restaurante-azure-ten.vercel.app)**

Carta digital en 3D para un restaurante ficticio. Cada plato se ve desde arriba, en relieve, y al tocar un ingrediente aparece qué es y sus alérgenos. Tiene cesta, pedidos, reservas, códigos QR por mesa y un panel de cocina.

## Alquinaterra

**[Probar la demo](https://alquinaterra-web.vercel.app)**

Maqueta de web para un herbolario. Un árbol fotorrealista ocupa el fondo y gira mientras haces scroll, con tarjetas fijas encima: categorías de producto, reseñas, horario y contacto. Modo claro y oscuro.

## PalaReserva

**[Probar la demo](https://palareserva.vercel.app)**

Web para que los clubes de pádel gestionen sus reservas. El jugador reserva desde el móvil sin crear cuenta y el club lo controla todo desde su panel: agenda, pagos, premios, reservas fijas y clases. Tiene una página de presentación con acceso directo para probarla como jugador, recepción o encargado.

## Notas

En todos los proyectos el contenido y los datos son de ejemplo. El código no está publicado aquí.
